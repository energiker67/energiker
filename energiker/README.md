# Energiker

Website der Energie-AG am Krupp-Gymnasium Duisburg.

## Dateien

- `index.html` – Seite
- `css/style.css` – Design
- `js/data.js` – Inhalte (Woche, Termine, Team, To-Dos)
- `js/main.js` – Logik
- `favicon.svg` – Tab-Icon

## Inhalte ändern

Nur `js/data.js` anpassen. Die Seite baut sich daraus selbst auf.

## GitHub Pages

1. Repo anlegen und diese Dateien hochladen
2. Settings → Pages → Branch `main` (Root)
3. Nach ein paar Minuten ist die Seite live
